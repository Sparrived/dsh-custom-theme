# dsh-custom-theme v0.4.6 — 2026-10-09

The reasoning levels this plugin fills in stop speaking for the model. The auto-filled `off` level is
now written without a wire value, so the requests that name no level — automatic compaction and
session titles — are no longer given one. A GPT model that had been filled in answered 400 on
compaction before this build. The level menu, the slider and the settings switch look exactly as
they did.

**本次更新**：修复「推理档位自动补全」把 `off` 档写成 `"off": "off"` 导致 GPT 模型**自动压缩**报 400 的问题——`off` 不再携带下发值，压缩这类不带档位的请求不会再被塞参数。

## Changed

- **`off` 档不再写下发值。** 补出来的块从 `"off": "off"` 变成 `"off":`（键仍加引号：YAML 会把裸 `off` 读成布尔）。
  于是带值的 `off` 不再进入 pi-ai 的 thinking map，shell 读作 "supported, send nothing"，各格式再说自己那句话：
  DeepSeek 格式路由发 `thinking: { type: "disabled" }`，Responses 系与 OpenRouter 等发 `effort: "none"`。
- **在 OpenAI 兼容（`openai-completions`）路由上，「选 Off」现在的含义是"不下发 `reasoning_effort`"**（网关自身默认）。
  若某个网关需要显式拼写，在它自己的档位表里手写一行 `"off": none` 即可——手写档位表插件永远不碰。

## Fixed

- **GPT 模型的自动压缩不再报 400。** pi-ai 对"声明了带值 `off`"的模型，会在**每个不带档位的请求**上发送那个值；
  自动压缩与会话标题正是不带档位的请求（`purpose: "compaction"` / `"session-title"`），而 OpenAI 系网关把"关闭思考"
  拼作 `none`，收到 `off` 直接 400——压缩因此失败。现在这类请求不再携带 `reasoning_effort`。
- **老版本写下的块会自动修好。** 补全 pass 幂等，下次 DSH 启动时把 `"off": "off"` 原地刷成 `"off":`。识别靠
  `# dsh-custom-theme:managed` / `:managed-from-false` 标记，第一次改动前留下的
  `<profile>/cordis.patch.yml.dct-backup` 不受影响；`reasoningEfforts: false` 的还原语义也不变。

## Upgrade notes

- 升级后**重启一次 DSH**：profile 在启动时读取，补丁要重启才生效。
- **不需要重新配置**：开关状态（`$DSH_HOME/dsh-custom-theme.effort-levels.json`）与设置卡片不变。
- 你手写的档位表（含手写的 `"off": <值>`）**不会**被改动——插件只动带自己标记的块。

## 中文摘要

- **修复**：自动补全的 `off` 档不再写死下发值（原 `"off": "off"`）。pi-ai 会在所有"不带档位"的请求上发送它，
  而 GPT/OpenAI 系网关只认 `none`，于是**自动压缩**报 400；现在 `"off":` 留空，这类请求不再被塞参数。
- **行为**：选 Off 时由格式决定——DeepSeek 格式发 `thinking disabled`，Responses 系/OpenRouter 发 `effort: "none"`；
  OpenAI 兼容路由上等于"网关默认"（要显式关闭就在自己档位表里手写 `"off": none`，插件不碰手写表）。
- **升级**：升级后重启一次 DSH；开关与设置不用动；旧版本写的块会在启动时自动刷成新写法。
- **验证**：`npm test` 219/219；`test:effects` 6/6；把旧写法放回去会让两个套件分别掉到 8/11 与 27/28（已实测）。
