# dsh-custom-theme v0.3.1 — 2026-10-06

The background picture now behaves the way it looks like it should: one whole-window image
instead of a crop per column, still there after switching conversations, and no longer replaced
by the upload that stored it. This release also brings Deeptop's reasoning auto-expand — the live
reasoning block unfolds itself while the model thinks and folds away when it stops.

**本次更新**：修复自定义背景图的三个问题（整体图不再逐区域裁剪、切换会话后不再消失、上传回来的结果不再覆盖新选择），并从 Deeptop 移植「思考内容展开」。

## Added

- **Reasoning auto-expand**, ported from Deeptop, under **思考内容展开** in Appearance. The live
  reasoning block (`[data-variant="think"]`) unfolds itself while thinking deltas stream in, and
  folds back into its one-line summary chip once the turn stops thinking. Historical reasoning
  blocks are left alone unless asked otherwise.
- Four modes to choose from: **仅思考中展开（结束后折叠）** (`streaming`, the default),
  **思考中展开并保持（结束后不折叠）** (`keep`), **始终展开（含历史消息）** (`always`), and
  **跟随官方（默认折叠）** (`off`), which injects nothing and leaves the shell to draw the
  reasoning row exactly as it did before. A click on the reasoning header is remembered, and that
  block is then left alone.

## Fixed

- **A whole-window picture was cropped once per zone.** The frame cannot be painted behind the
  shell's opaque columns, so the picture goes on every zone — and each zone then measured the
  image against its own box, which is what turned one picture into a band per column and per bar
  with seams between them. A spread picture is now anchored to the viewport instead, so every zone
  shows its own window onto the same picture. A zone with a picture of its own still covers that
  zone, which is what picking one for that zone means.
- **Switching conversations left the conversation half bare.** Opening a conversation makes the
  shell throw the column, its header and the composer seat away and build new ones, and the
  markers and inline declarations the plugin had written went with the old elements — only the
  sidebar, which is never rebuilt, kept its picture. The plugin notices now and paints the zones
  again, so the picture follows the shell.
- **A picture could be overtaken by the upload that stored it.** Picking a file is a round trip,
  and the picture was selected whenever that trip finished, so a choice made while it was in
  flight — from the list, or from a second file — was replaced by whichever landed last: the
  picker showed one picture and the window another. The upload now only selects its picture while
  the zone still holds what it held when the file was picked. The file is stored either way.

## Upgrade notes

Nothing to do: install the new version and restart. A picture that is already configured is
re-anchored to the window the next time it is painted, which is the fix itself, and zones that
carry their own picture are unaffected. 思考内容展开 starts on **仅思考中展开（结束后折叠）**, so
reasoning blocks begin unfolding on their own — pick **跟随官方（默认折叠）** to keep the previous
behaviour.

## Verification

- `npm test` — 81 tests, passing, of which 7 cover the reasoning modes (default, the allowed
  choices, each mode's behaviour over a streaming and a finished block, and that a clicked header
  is left alone).
- `npm run test:effects` — 6/6 steps, passing; needs no DSH and no token.
- `npm run test:working` — 10/10 steps, and `npm run test:browser` — 39/39 steps, both passing
  against a live DSH window with this build installed, driven through headless Edge. The browser
  suite includes the two background regressions themselves: that a spread picture is anchored to
  the viewport on every zone it reaches while a zone's own picture is not, and that a surface the
  shell rebuilds is painted again.
- By hand: the assembled window with a whole-window picture, before and after the shell replaced
  the surfaces it had painted — one continuous gradient with no seams in both, which is what the
  two regressions looked like before the fix.
- Not covered by any command: the reasoning block unfolding during a real turn with thinking
  output. Its modes are exercised against DOM doubles only.

## 中文摘要

- **背景图三个修复**：整体图不再按区域各自裁剪（改为锚定窗口，一张图贯穿整个窗口）；切换会话时 shell 重建界面后图层会自动重绘，不再半侧消失；从文件对话框选图不再被上传回来的结果覆盖。
- **新增「思考内容展开」**（从 Deeptop 移植）：思考时自动展开推理过程、结束后折叠回单行摘要；可选「仅思考中展开（默认）」「思考中展开并保持」「始终展开（含历史消息）」「跟随官方（默认折叠）」；手动点过展开/折叠后该块不再被自动干预。
- **升级**：装上重启即可；已配置的背景图下次绘制即按新方式对齐，自带图的区域不受影响；不想要自动展开就选「跟随官方（默认折叠）」。
