# dsh-custom-theme v0.6.0 — 2026-10-15

This release turns the plugin into a set of rows: every feature the settings page configures is now its
own row on DSH's 「插件」 page, with its own name, description and icon, so you can see what the package
brings and which part of it is mounted. The settings page follows — six grouped tabs in place of one
long column — and the reasoning-effort slider gains two more looks, a Google four-colour aurora and a
Claude terracotta spark.

**本次更新**：插件拆成 9 个可独立挂载的子插件行（「插件」页逐行可见），设置页改为 6 个分组标签页、某行没挂载时对应卡片会明说；思考深度滑块新增「Gemini 四色极光」与「Claude 陶土星芒」。

## Added

- **九个子插件行**（设置 → 插件）：在 `dsh-custom-theme` 之外多出 CSS 主题与配色、多区域背景图片、字体排版与流式渐显、思考模型展示折叠、思考深度调节滑块、思考状态与动效、品牌定制与问候语、注入上下文显示、桌面系统托盘增强——每行有自己的名称、说明与图标。
- **设置页改版为 6 个分组标签页**：主题与背景、排版渐显、注入显示、思考与滑块、状态与品牌、桌面与更新；11 张卡片各归其组。标签栏优先用 shell 的 `SegmentedControl`，取不到时退回自带的 `role="tablist"`。
- **某行没挂载时卡片会明说**：九张受控卡片会向宿主查询已挂载的行；行不存在时显示虚线面板，提示到「插件」页把开关打开，而不是画一堆点了没反应的控件。
- **滑块新增两种风格**：「Gemini 四色极光」（Google 四色渐变带、三种大小的四角星屑、旋钮旁两颗环绕的小星）与「Claude 陶土星芒」（随档位加深的陶土渐变、按三种节奏开合的象牙色星尘、旋钮上一枚缓慢自转的十二芒星），与 Codex 星空、DeepSeek 深海并列。
- **插件有了自己的图标**（`icon.svg`，DSH 里作为该插件的标识），设置页顶部多一行说明：功能开关在「插件」页，这里只放配置。

## Changed

- **设置页的形状变了。** 以前是一条长列、滚动就能碰到控件，现在要先选分组：11 张卡片被分进 6 个标签页，未激活标签页的卡片不显示。分组也调整过——背景图片并入「主题与背景」，桌面托盘与插件更新成为最后一组的两张卡片。
- **思考深度滑块从「高级与注入提示」卡片里独立出来**，与「思考内容展开策略」同组。
- **四种滑条风格的主题互斥**：`.ces-whale-track` 以前只对 `codex` 风格隐藏，现在除 DeepSeek 风格外一律隐藏；Gemini 星轨与 Claude 星芒同样只在各自风格里出现——鲸鱼不会再横穿四色极光。
- **「减少动态效果」的覆盖范围扩大**：Gemini 星屑、旋钮旁的双星与 Claude 星芒一并停动；Claude 的星尘保持尺寸、不再开花。
- **英文界面下新页面文案已补齐英文**：标签页名、分组名、说明行与「未挂载」提示都进了 `en`/`zh` 词典，英文 shell 读到的是一整页英文。

## Fixed

- **鲸鱼不再游到其它风格的滑条上。** 旧选择器只把 `codex` 当作要隐藏鲸鱼的那一种风格；四种风格并存时，这条规则会让 DeepSeek 的鲸鱼横穿四色极光与陶土星芒。这是 0.5.0 就埋着的问题，只是当时只有两种风格、不会显形。
- **设置页顶部不再写死版本号**（原先固定写着 `0.5.0`）：运行中的版本由「插件更新」卡片从宿主读取，页面本身不再复制一份会过期的数字。
- **标签与它对应的面板重新互相指名**（对读屏用户可见）：真实渲染下标签的 `aria-controls` 指向 `custom-theme-tabs-<id>-panel`，而页面给面板的 id 是 `custom-theme-tab-<id>-panel`，面板的 `aria-labelledby` 又指着另一种渲染才有的标签 id——两个方向都是悬空引用。现在两边都由"是谁画的标签栏"这一个基准推出，实机套件也改成顺着标签自己的 `aria-controls` 找面板，接线再断就会直接红。

## Upgrade notes

- 升级后**重启一次 DSH**：九行来自本包自己的 `cordis.patch.yml`，重启时随 profile 一起组装；只认旧单行的 profile 会把九张卡片都显示成「这一行没有挂载」。
- **设置不需要迁移**：主题、背景、字体、品牌与文案的存储键、设置页 id 与命名空间都没变；滑块风格仍是 `dsh-custom-theme.effort-theme`，新风格只是多了两个合法取值。
- **目前关掉某一行只会隐藏它的设置卡片**：真正应用主题、背景、排版、运行文案与托盘补丁的运行时仍挂在主行 `dsh-custom-theme` 上，所以「关掉一行 = 关掉一个功能」还不是这一版能做到的事（已在 CHANGELOG 的 Notes 里记明）。
- **如果你在「插件」页关掉过 `dsh-custom-theme` 这一行，升级后请把它打开。** 九个子插件行都是从子路径挂载的，**只有主行携带浏览器半边**（设置页与外观集成都在那一半里）：主行关着时，九行仍会挂载它们那一小段宿主初始化，但设置页不会出现——旧版"关掉这一行 = 关掉整个插件"的粗粒度开关，从这一版起不再等价。
- 在设置页的**插件更新**卡片里「检查更新 → 升级」即可拿到这一版（从 npm 装好，重启后生效）；或按你平时的方式把 profile 依赖升到 `0.6.0`。

- `npm pack --dry-run --json` — 128 files，314.0 kB packed（1056.3 kB unpacked）；`test/`、`releases/` 与 `.dsh/` 都不在包里。
- `npm run test:browser` — 46 steps（本版给标签页新增 7 步），45 通过 / 1 失败：唯一失败是
  `a global image paints every zone and is visible in them`（`composer layer image was none`）。该步骤要求每个区域**自带**一层图片，而嵌套区域的图层是刻意去重的——composer 锚点落在会话区内部，与它显示同一张图时不再叠第二层（两层 alpha 叠起来会比用户设定的更重）；同一份套件自己的可见性断言只采样整体/侧边栏/会话区三处。这条在 2026-10-10 的旧真机日志里以完全相同的方式失败，早于本次改版，因此按既有的记录方式如实列出，不当作本版回归。
- `npm run test:working` — 10/10 steps, passing（0.5.0 的说明里记过的那两步「需要带回合的会话」这次拿到了数据）。
- `npm run test:tray-ui` 与 `npm run test:popover` — PASS，两者都不需要 DSH、不需要 token。
- By hand: 桌面端（本机 `desktop` profile，link 安装指向本仓库）里访问 `/dsh-custom-theme/subplugins`，返回 `custom-theme` 加九个子插件 id，说明十行确实都已挂载。
