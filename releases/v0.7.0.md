# dsh-custom-theme v0.7.0 — 2026-10-16

This release is about two kinds of polish you can feel and see. Dragging the reasoning-effort slider no longer stutters: the starfield used to jump on every frame of a drag, the control wrote every level it passed through to the host, and each frame's paint landed a frame late — all three are gone, so the knob and the stars move as one. And the settings page trades its emoji pictograms for inline SVG icons, which follow the theme's label colour and render identically on every platform.

**本次更新**：推理等级滑条拖动不再卡顿——星空不再乱跳、拖动途中不再向宿主逐档写回、每帧渲染在帧内同步提交；设置页的 emoji 图标全部换成随主题变色的 SVG 图标。

## Changed

- **Reasoning-effort slider: a drag paints instead of writing.** While dragged, the knob no longer writes each level it crosses to the host (a `selectModel` call per level, kept in session history and reported to analytics). The level is written once, on release, and a release on the level already in force writes nothing. The shell's value text and the collapsed seat change when you let go, not mid-drag.
- **Settings icons: emoji → inline SVG.** Every card heading, the light/dark/system scheme capsule, the four effort-theme marks (Codex/DeepSeek/Gemini/Claude), the hint banners and the page heading were emoji glyphs, whose colour and shape depend on the platform's emoji font. Each is now a small stroke-drawn SVG in `currentColor`, so icons take the label colour of the active scheme and look the same on every OS.

## Fixed

- **The starfield no longer shatters while the knob moves.** Every star's animation timing was rewritten on every painted frame; a CSS animation re-maps its progress when its duration changes, so a drag nudged all twenty-two stars on every frame — the longer the menu had been open, the harder the field jumped. Each star is now written once, and the position's speed is the animations' playback rate, so a star speeds up and slows down where it is.
- **Each drag frame is committed inside the frame.** The render a frame asked for was left to React's scheduler, so the knob was a frame late and the next pointer event hit a dirty DOM. The frame callback now commits synchronously.
- **A pointer taken away from the track ends the drag.** `lostpointercapture` closes a drag whose release the page never saw (the window lost focus, the pointer was taken away).
- **A selected settings tab no longer nudges every other label off centre.** The selected tab's bold CJK label widened its grid column and re-centred every unselected sibling; the selected tab now paints its emphasis with a `text-shadow` at a fixed advance width.

## Upgrade notes

Nothing: upgrade and restart. Settings, themes and backgrounds carry over unchanged.
