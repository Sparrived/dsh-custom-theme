# dsh-custom-theme v0.9.0 — 2026-11-13

This release retires the streaming text effects and reasoning-expansion controls, and removes the custom
context-injection renderer now that DSH shows ordinary Context rows itself. It also deletes obsolete
diagnostics and design-only files. Themes, wallpapers, line spacing and the other current controls stay.

**本次更新**：移除流式渐显、写作墨水、思考展开及重复的上下文注入显示；保留正文行距、主题、壁纸等现有功能，并清理过期诊断与设计文件。

## Breaking changes

- **Streaming fade, writing ink and reasoning expansion are removed.** The `stream-ink` and `reasoning`
  sub-plugins are gone, together with the fade duration, ink strength, reasoning expansion mode and shortcut
  presets. The stored `streamingFadeDuration`, `streamingFadeInk` and `reasoningExpand` fields are ignored;
  the saved line-spacing choice is unaffected.
- **The duplicate context-injection display is removed.** DSH 0.2.2-rc.2 restores ordinary Context rows,
  including skills, workspace instructions and session references (upstream commit `44ad857`). The plugin no
  longer registers a second Conversation Definition or Chat node renderer. The `custom-theme-injections`
  sub-plugin and the 「注入显示」 settings tab are gone, so one event is drawn only by the official UI.

## Maintenance

- Removed the obsolete diagnostic suite, the unreferenced Gemini slider design demo and the old release skill.
- The browser bundle now contains 47 modules; the published package contains no removed `injections`,
  `stream-ink`, `reasoning` or diagnostic-suite files.

## Upgrade notes

- Existing features still require **DSH 0.2.1** or later. Official context-injection rows require
  **DSH 0.2.2-rc.2** or later; older DSH versions no longer get a replacement renderer from this plugin.
- Existing themes, backgrounds, line spacing and other current settings carry over unchanged. Settings for
  the removed effects and injection display are simply ignored.
- Restart DSH once after upgrading, as with any plugin update.
