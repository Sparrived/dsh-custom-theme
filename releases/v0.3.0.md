# dsh-custom-theme v0.3.0 — 2026-10-05

Streaming text now fades in as the model writes it, and the running indicator at the foot
of the transcript can be dressed with Deeptop's text effects — with 流光 rebuilt so it keeps
the matte finish the shell's own shimmer has. Custom themes also stop inverting the colours
of code blocks and diffs.

**本次更新**：流式输出的文字随写随显（渐显）；「工作时文字」新增文字特效（流光为官方哑光机制）；修复自定义主题下代码块与差异视图的配色反转。

## Added

- **Streaming fade-in.** Text arriving during a live turn is split into staggered
  `.stream-ink` spans so it fades in as it is written, and settled back into plain text
  once the turn stops writing. Two new **Appearance** controls drive it: **流式渐显时长**
  (`--stream-fade-duration`, 150–1500 ms, default 520 ms) and **落笔墨量**
  (`--stream-fade-ink`, 5 %–100 %, default 30 %; 100 % turns the fade off). It follows
  `prefers-reduced-motion: reduce` and renders text solid instead.
- **Working-text effects**, under **工作时文字**: 静态, 流光 (in 哑光 and 七彩光) and 隐藏,
  with 跟随官方 as the default that injects nothing at all. Two colours and a rotation
  interval of 1.2–10 s are configurable, and the section shows a sample of the running
  label that wears the same rules, so an effect can be judged without starting a turn.
- The effect is a stylesheet of its own, added and removed with the plugin, addressing the
  marks the shell puts on that row rather than its hashed class names. A chosen colour
  never reaches message text, and text streams are never touched.

## Changed

- 流光 is the shell's own mechanic rather than Deeptop's gloss: the label keeps one solid
  colour and only the band sweeping across it takes a tint, through the very token the
  shell paints that band with. The shell's mask, its two animations and its
  reduced-motion handling are left whole.
- The second colour choice is **扫光颜色** (the band's tint) instead of a gradient colour,
  and it is not offered for 七彩光, whose spectrum is fixed.

## Fixed

- **Code blocks and diffs no longer invert under a custom theme.** Custom theme
  stylesheets no longer leak `--*` custom properties into the page, so a light-mode
  `:root` can no longer shadow dark-mode tokens; `--shiki-foreground` and
  `--shiki-background` are synthesised per active theme; and non-token dark rules follow
  `body[data-ds-dark-theme]`, which is the attribute this shell uses.

## Upgrade notes

Nothing to do: install the new version and restart. A configured phrase list, interval and
colour keep working. Both colours have defaults (text `#4176e6`, sweep `#5ee0ff`) and are
set under **工作时文字**.

## Verification

- `npm test` — 74 tests, passing, of which 27 are the browser half's own, materialized
  through the doubles in `test/harness.mjs`: the wording cases, one per effect choice, the
  streaming fade's sheet, and the theme fix.
- `npm run test:effects` — 6/6 steps, passing. It needs neither DSH nor a token: it stands
  the shell's running row and the page's sample up as fixtures and counts the pixels that
  change, which is what pins the matte mechanic down (the band tints the end it has reached

## 中文摘要

- **流式文字渐显**：模型边写边显，新增「流式渐显时长」（150–1500 ms，默认 520）和「落笔墨量」（5%–100%，默认 30%，100% 关闭）两个外观设置；系统偏好减少动态效果时自动跳过。
- **「工作时文字」文字特效**：静态 / 流光（哑光、七彩光）/ 隐藏，默认「跟随官方」不注入任何样式；两种颜色与 1.2–10 s 轮换间隔可调，设置页下方有示例可直接预览。
- **流光改为官方哑光机制**：文字保持实色，只有扫过的那条光带被染色，用的是 shell 自己的遮罩与动画；原来那个「渐变调色」颜色项改名为「扫光颜色」，七彩光不提供该项。
- **修复**：自定义主题不再把代码块、差异视图的配色弄反（不再向页面泄漏 `--*` 变量，并按主题生成 shiki 前景/背景色）。
- **升级**：装上重启即可，已配置的短语、间隔与颜色都保留。
