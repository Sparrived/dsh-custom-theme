# dsh-custom-theme v0.10.0 — 2026-11-22

**本次更新**：Prism 主题扩展至三套，Gemini 滑条新增四色流光点阵，像素小猫可从热力图跳到输入框上沿。

## 新功能与改进

- **Prism 主题系列**：雾紫 / 墨紫之外，新增冷晶 / 黑曜与暖白 / 暖炭。三套共用输入框焦点描边、按钮圆角与按压回馈、实心发送按钮内嵌高光，以及菜单与页签淡入；遵循减少动态效果设置。
- **主题色**：可用预设或自选颜色调整按钮、链接和焦点环，不改变画布与文字层级；自动调整明暗对比。
- **Gemini 推理滑条**：保留四色渐变底光，叠加六排等尺寸像素。波光从右向左流动，部分像素错峰明灭，点阵不移动、不缩放；减少动态效果或强制颜色模式下不播放。
- **像素小伙伴**：小猫可在输入框上沿呼吸、眨眼；开启热力图时先待在热力图右上角，再跳回输入框。「创意组件」可开关或调节它的水平位置。
- **开始页热力图**：上方展示六项使用统计（含缓存命中率）；支持全部 / 30 天 / 7 天统计范围，保留 26 周热力图。
- **界面交互**：审批、问题和方案审阅卡新增待处理高亮；设置页签补充键盘操作，切换主题失败时保留当前外观；收敛界面文字选中范围。

## English highlights

- Three light/dark Prism palettes, unified control feedback and a customizable accent that leaves canvas and text colors alone.
- Gemini’s effort slider now pairs a four-color gradient with a six-row pixel matrix, a horizontal light wave and staggered twinkles. Reduced-motion and forced-color preferences suppress the animation.
- A pixel cat can hop from the usage heatmap to a configurable perch along the composer. The usage overview now offers six metrics and all-time, 30-day and 7-day summaries alongside a 26-week heatmap.
- Pending-action cards gain a highlight, settings tabs gain keyboard navigation, and a failed theme load no longer clears the current theme.

## Upgrade and verification

- Update via the DSH plugin manager or install [dsh-custom-theme@0.10.0](https://www.npmjs.com/package/dsh-custom-theme/v/0.10.0), then restart DSH.
- Existing saved preferences carry over. Find the slider and pixel companion under 「创意组件」 / Creative Components.
- 251 automated tests, client/theme build consistency checks, and an npm package contents check. Gemini slider input and animation were additionally exercised in an isolated Edge fixture.
