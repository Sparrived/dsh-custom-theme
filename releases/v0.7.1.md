# dsh-custom-theme v0.7.1 — 2026-10-17

DSH 0.2.1 gives the font controls a home of their own: 「设置 → 通用」 now offers text, code and
terminal sizes and families, with Cmd/Ctrl +/- on the desktop. This release deletes the plugin's
duplicate rows and leaves the typography card with what the shell does not cover — line spacing and
the streaming fade. Everything else keeps its settings.

**本次更新**：官方「设置 → 通用」已接管字号与字体，插件删除了重复的字号胶囊与字体选择；排版页保留官方没有的正文行距与流式渐显。

## Changed

- **Font size and font family are now the shell's settings.** The 字号 capsule (12–17px), the
  正文字体 presets and the 代码字体 presets are gone, together with the `--dsw-font-family` /
  `--ds-font-family-code` overrides, their preset lists and their i18n strings. The 「排版渐显」
  card is now just 正文行距 plus 流式渐显. The official General pane offers text, code and terminal
  sizes (defaults 14, 11 and 13 px), a family for each, and Cmd/Ctrl +/- moves all three sizes on the
  desktop.
- **Line spacing still layers on the official line height.** The plugin's stylesheet writes only
  `--dsh-content-font-delta: calc(var(--dsh-content-font-size, 14px) - 14px + Npx)`. The 0.2.1 body
  line height is derived from that delta, so a +3px choice stays +3px after the official 正文字号
  changes. At the default 0px the stylesheet stays empty.

## Fixed

- **The old font-size capsule threw on DSH 0.2.1.** The official theme service replaced
  `setFontSize(px)` with a role-aware `setFontSize(role, px)`, and its snapshot's `fontSize` became
  `fontSizes`/`fontFamilies`; the old control called the removed shape and errored when used. With the
  control deleted the error path is gone — fonts are set in 设置 → 通用.

## Upgrade notes

- Requires **DSH 0.2.1** or later.
- Font size and fonts: use **设置 → 通用**. A font family the plugin used to apply stops applying;
  pick it again in the official pane, whose defaults are 正文 14px, 代码 11px and 终端 13px.
- Everything else is untouched: themes, wallpapers, line spacing (`lineGap`) and streaming-fade
  settings stay as stored. No cache clear or reinstall needed; restart DSH once after the upgrade.
