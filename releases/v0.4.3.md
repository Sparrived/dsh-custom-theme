# dsh-custom-theme v0.4.3 — 2026-10-07

Reasoning effort stops being a row of stops: the model menu now carries a slider you can drag, with
the level's own colour and a starfield that thickens as it climbs. Models that never declared any
thinking levels are given them, the context rows the app hides come back behind a switch, and the
picture 0.4.2 dropped is drawn again.

**本次更新**：模型菜单的推理档位变成可拖拽滑条；未声明档位的第三方模型自动获得档位；被隐藏的上下文注入行可用开关找回；0.4.2 弄丢的整体壁纸恢复显示。

## Added

- **The reasoning-level row is now a slider you can drag.** One continuous track under the model menu,
  a fill that runs blue → violet → deep violet as it climbs, the level's name coloured in the row and
  on the collapsed model pill, and — from the second level rightwards — a purple nebula whose 22 stars
  thicken, quicken and brighten as the knob travels. Dragging anywhere on the track selects the nearest
  level; the arrow keys step one level at a time and Home/End jump to the ends. The style is chosen in
  Settings: **Codex 星空** starfield, or **DeepSeek 深海** with a whale crossing the track.
- **Climbing into the top level says what it costs.** Landing on Max draws **将使用更多额度 / More
  quota will be used** over the row's own value cell in that level's colour, and one second later the
  line turns over to show the level's name. The notice paints no background of its own, takes no
  clicks, and only appears when you move into the top level — opening the menu already sitting there
  says nothing.
- **Models that declared no thinking levels now have them.** A third-party model whose gateway never
  spelled its reasoning levels out showed no effort row at all, and any level you picked by hand was
  refused before the request was built. Such models now get `off` / `low` / `high` / `max` in your
  profile. **自动补全推理档位** in Settings shows what the file holds and takes the whole set back out
  again.
- **The hidden context rows come back, behind a switch.** Everything the harness injects into the
  model's conversation — a skill's instructions, the skill catalog, the workspace's rules, a session
  recall, a notice — is logged, but the installed build draws a row for it only when the injection also
  added or removed a tool, so an ordinary injection is invisible in the transcript. **注入提示 /
  Injection notices** restores those rows where they belong.
- **A front page in two languages.** `README.md` is Chinese and the one a visitor lands on;
  `README.en.md` is its English twin. Both ship in the package, and every picture in them was taken
  from a running app.

## Changed

- **Dragging costs one frame of work per frame, not one per pointer event.** Each pointer event used to
  run a full update: a render pass, style writes on the row, on its value cell and across the track's
  layers, and a measurement that made the browser lay the page out again before every one of them. On a
  165Hz display that is a great deal of work for frames nobody can see — on a laptop whose wallpaper
  was animating, dragging the knob made the wallpaper stutter too. The knob now paints once per
  animation frame, the track is measured once for the whole gesture, and the starfield is kept rather
  than rebuilt. Nothing about the picture changes, and a release still lands on the level the pointer
  was over.
- **Reduced motion slows the crossing instead of removing it**: with `prefers-reduced-motion` on, every
  crossing takes 2.6× longer and the nebula's sweep is dropped.
- **The plugin is laid out as two halves with an explicit module graph.** The browser half — a single
  5,787-line bundle — is now 38 CommonJS modules linked back into the same one-file artifact, and the
  host half is a thin row over its own modules. Every route, string, stylesheet and selector is
  unchanged; `ARCHITECTURE.md` is the map, and the suite fails if the bundle and its sources drift
  apart.

## Fixed

- **The whole-window picture disappeared.** 0.4.2 taught a zone nested inside another to skip its own
  picture layer when one was already painted behind it. Every zone is nested inside the window frame,
  and the frame is painted too, so that single layer took the picture off the sidebar, the conversation,
  the composer and the right bar at once. A zone now skips its own layer only when the picture already
  behind it is the very same one.
- **The composer's mask was written off.** 0.4.2 also cleared the gradient the composer keeps. That
  gradient is what holds the bottom of the transcript back, so a reply scrolling past the input showed
  through it and the input read as a floating box. The seat's own background is left alone again; the
  only fade this takes out of the way is the workspace list's, at the bottom of the sidebar.
- **Switching sessions no longer leaves the conversation bare.** The shell renders the conversation's
  column one commit before the panel that fills it, and a pass landing in that gap painted the picture
  on the column and then had it covered by the panel. The column stayed in the document, so the
  "was anything I painted taken away?" test could not see it and that session kept a bare conversation
  until the next reload. The pass now also repaints when the shell adds an element inside a zone.

## Upgrade notes

Nothing to do: update, restart the app, and everything you had configured keeps working. Your themes,
wallpaper zones, opacity, blur and typography are untouched.

- **The reasoning-level patch is on by default and edits your profile's `cordis.patch.yml`.** It only
  touches models that declare no levels (or `reasoningEfforts: false`), every line it adds carries a
  `# dsh-custom-theme:managed` marker, the first edit keeps a `<file>.dct-backup` copy beside it, and
  the write goes to a temporary sibling that is then moved into place, so a crash mid-write cannot
  leave a half-edited profile. The switch takes the whole set back out, restoring a `false` it replaced
  exactly as it was. The profile is read at boot, so the row says **重启 DSH 后生效** until DSH
  restarts.
- **Worth a look after upgrading**: **注入提示** to bring the context rows back, **滑条特效风格** to pick
  between the starfield and the deep-sea whale, and **运行状态文案** if you want the thinking label to
  say something of your own.
- A model that declares its own reasoning levels is never touched by the patch, and a profile whose
  patch file cannot be found is reported rather than guessed at.

## 中文摘要

- **推理档位滑条**：模型菜单里的档位行改成可拖拽滑条，连续轨道 + 蓝→紫渐变填充，第二档起出现 22 颗星轨组成的紫色星云；支持拖拽吸附、方向键步进、Home/End 跳转，风格可在「Codex 星空」与「DeepSeek 深海」之间切换。
- **额度提示**：拖到最高档 Max 时，会在档位数值处以该档颜色提示「将使用更多额度」，1 秒后翻面显示档位名；不遮挡点击、不额外绘制底色。
- **第三方模型档位补全**：未声明推理档位的模型（网关没写 levels 的）此前既没有档位行、手选也会被拒；现在自动补上 `off/low/high/max`。设置页开关可整体撤销并还原被替换的 `false`，首次修改会留下 `.dct-backup` 备份。
- **上下文注入行恢复**：被官方过滤掉的「技能说明 / 技能目录 / 工作区规则 / 会话回忆 / 通知」等注入行，可用「注入提示」开关找回。
- **修复**：0.4.2 导致整体壁纸消失（嵌套区域误跳过图层）与输入框上方渐隐被清除（回复会透过输入框）已修好；切换会话不再丢失会话区背景。
- **性能**：拖拽从「每个指针事件一次更新」改为「每帧一次」，165Hz 屏上不再拖累桌面壁纸动画。
