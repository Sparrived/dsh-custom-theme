# dsh-custom-theme v0.4.1 — 2026-10-06

This release is for two things you can feel rather than read: a streaming reply's fade-in no longer
makes the app stutter, and switching conversations no longer flashes a bare column before the
picture comes back. The fade's appearance and its settings are unchanged.

**本次更新**：修好流式渐显的卡顿与会话切换时背景一闪的问题，渐显的外观与设置完全不变。

## Changed

- **The fade-in stops competing with the app.** While the writing ink ramps, the plugin now does no
  work at all: the ramp is one CSS animation of a registered property, and the highlight rule reads
  its alpha from that property. Before, the plugin rewrote its own stylesheet about thirty times a
  second for as long as characters kept arriving, and re-scanned the document for every chunk. A
  chunk now costs one animation, however long the reply is.

## Fixed

- **The stutter while a long reply streams.** With the fade on, the app's frames went into the
  plugin instead of into the reply, and the shell's own deferred work — rendering a long reply's
  maths, for one — had to queue behind it.
- **The flash when switching conversations.** The picture left with the old conversation column and
  only came back a moment later. It now comes back in the same frame the new column is built, so
  the column is never shown bare.

## Upgrade notes

- Nothing to do: upgrade, restart DSH, and the fade is where it was. Your duration and writing ink
  settings are kept, and 100% still turns the fade off.
- If a long reply's maths still appears only after you re-enter the conversation, that delay is not
  this pressure — please say so, because it would point somewhere else.

## Verification

- `npm test` — 86 tests, passing.
- `npm run test:effects` — 6/6 steps, passing; needs no DSH and no token.
- `npm run test:working` / `npm run test:browser` — not run: both need a live DSH window and a
  `DCT_TOKEN`, and this run had no token available.
- By hand: the new ramp was driven in a real browser (headless Edge) with the exact rule,
  registration and animation the plugin uses. The highlight's resolved alpha tracked the animation
  at every point of the ramp (0.2 → 0.592 → 0.894 → 1), and a highlight with no animation came back
  at the registered initial value.

## 中文摘要

- **卡顿修好了**：流式渐显不再每秒重写几十次样式表，也不再为每一个新字符重扫一遍文档；渐显本身改成一条 CSS 动画，插件在整个渐显过程中不做任何事。
- **切换会话不再闪**：背景图现在与新建的对话列在同一帧里重画，不会再先露出一列没有背景的窗口。
- **渐显外观与设置不变**：时长、书写墨色照旧，100% 仍是关闭。
