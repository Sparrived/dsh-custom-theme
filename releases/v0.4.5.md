# dsh-custom-theme v0.4.5 — 2026-10-08

Clicking a session in the tray menu opens it again. 0.4.4 listed your unread and recent sessions
correctly, but the click itself never arrived: every row in the popup and in the native
right-click menu did nothing, and the popup stayed open as if the click had been swallowed. The
menu, the double click that raises the window, the right-click menu and the settings switch are
unchanged.

**本次更新**：修好托盘菜单里点会话不跳转的问题——0.4.4 里点哪条都没反应，现在点哪条就打开哪条，弹窗也随之关闭。

## Fixed

- **点会话行会打开它了。** 主进程把动作当成 JSON 字符串交给渲染器，而渲染器要的是动作对象：
  字符串没有 `type`，被判为非法、返回 `false`，弹窗只在收到 `true` 时才关闭，于是既不跳转也不消失。
  左键弹窗与右键原生菜单里的会话行都受影响；「新建会话 / 打开 DeepSeek Harness / 退出」一直是正常的。
- **这类错误不会再被测试放过。** 原来的测试对注入的表达式一律回答 `true`，等于只校验了函数名；
  现在它把表达式放进一个与渲染器等价的接收者里求值，并逐字断言到达的对象——把旧写法放回去会让套件
  失败（已实测），客户端那侧也用一条断言把「不接受字符串」钉住。

## Upgrade notes

- **升级后重启一次桌面端**，补丁在启动时由 Host 重新施加；当前已打开的那次运行不会自己变好。
- 开关与设置卡片不变，不需要重新配置。

## Verification

- `npm test` — 218 tests, passing.
- `npm run check:client` — the linked browser bundle is in step with its sources.
- `npm run test:effects` — 6/6 steps, passing; needs no DSH and no token.
- `npm run test:tray-ui` — the menu document in a real Chromium: text safety, light/dark, keyboard,
  more/back, actions, errors and the content-sized layout.
- `npm run test:working` / `npm run test:browser` — not re-run for this build: they need a live
  `dsh web` window and its token, and this release changes only the Desktop main-process payload,
  which they do not exercise. They were run against the 0.4.4 tarball in this same session
  (`test:working` 10/10; `test:browser` 38/39, the one failure reproduced identically on the
  published 0.4.3 artifact, so it is an artifact of a headless web run).
- The regression test was checked by mutation: restoring the old double-`JSON.stringify` line makes
  `test/desktop-inject.test.mjs` fail 13/14, and the fix makes it 14/14.
- By hand, in the running DSH Desktop: the fixed payload was injected into the live main process,
  the popup was opened, and a real row was clicked inside the real popup — the conversation on
  screen changed from the session it was showing (3 turns, 「已完成，用时 8分48秒」) to the one that
  was clicked (1 turn, 「已完成，用时 39分12秒」), and the popup closed itself. The same click was
  then repeated against the payload extracted from **this release's packed tarball**, with the same
  result.
