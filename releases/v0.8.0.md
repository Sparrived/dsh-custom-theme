# dsh-custom-theme v0.8.0 — 2026-10-24

This release adds two surfaces. The Claude theme gives the whole shell the warm neutral palette and
serif reading face of Claude Code Desktop, with light and dark variants. The start-page usage heatmap
turns the local session list into a 26-week token overview above the composer, with six stat cells and
All / 30d / 7d views. The heatmap also stops doing work in conversations, so a long answer no longer
keeps rebuilding a hidden card and its date formatters.

**本次更新**：新增 Claude 主题与开始页用量热力图；热力图只在开始页工作，进入会话后不再订阅会话列表，长回答时不会再把桌面端渲染进程拖慢甚至拖崩。

## Added

- **Claude theme.** A warm off-white / warm black shell with terracotta `#d97757` as the accent, a
  neutral-warm gray scale across the sidebar, transcript, code blocks and composer, and a serif body
  face while code and controls stay sans-serif. `themes/claude.css` carries both the light and dark
  palettes and follows the active scheme.
- **Start-page usage heatmap.** A standalone `custom-theme-heatmap` row draws the last 26 weeks of
  local session usage between the greeting and the composer. It shows sessions, total tokens, active
  days, peak hour, daily tokens and top model, with All / 30d / 7d views for the stats while the grid
  keeps its 26-week window. Every figure comes from the shell's local `tokenUsage`,
  `sessionListMetadata` and `modelSelection` projections: no new Host route, no session-log scan.
  Blank drafts and subagent rows are excluded; a session's tokens are placed on its last-prompt day.
- **Placement and switch.** The card sits after the greeting and before the workspace / mode row, and
  Settings → 主题与背景 → 热力图 turns it off independently; when off it takes no space above the
  composer. The `custom-theme-heatmap` row on the Plugins page remains the feature's master switch.

## Fixed

- **The hidden heatmap no longer keeps a conversation's session-list subscription alive.** The card
  is unmounted outside the hero phase, so the 182 cells, tooltip strings and date formatters are not
  rebuilt while an answer streams. On the start page the list refresh is throttled to 400ms, and the
  day formatter and day labels are cached instead of creating `Intl.DateTimeFormat` instances for
  every cell on every render. This removes the renderer-memory/CPU path that could make DSH Desktop
  crash during long answers.

## Upgrade notes

- Requires **DSH 0.2.1** or later.
- The heatmap is **on by default**. If you do not want it, turn it off in **设置 → 主题与背景 → 热力图**;
  the setting is stored locally and the card leaves no gap when disabled.
- To use the Claude theme, select **Claude** in **设置 → 主题与背景 → 主题**. It has both light and
  dark palettes and does not change any other saved setting.
- Restart DSH once after upgrading, as with any plugin update. Existing themes, backgrounds, line
  spacing and other settings carry over unchanged.
